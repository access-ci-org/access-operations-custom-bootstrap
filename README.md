# ACESS Operations Custom Bootstrap

Documentation : https://access-ci-org.github.io/access-operations-custom-bootstrap/

## NPM

This package is not yet availabale in the npm registry. But, it can be installed and used through github as follows.

### Install the latest version
`npm install github:access-ci-org/access-operations-custom-bootstrap --save`

### Install a specific version
`npm install github:access-ci-org/access-operations-custom-bootstrap#v0.0.12 --save`
